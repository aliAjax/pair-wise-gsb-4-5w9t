# 声线练习室

纯前端英语发音练习应用（Vite + React）。`npm run dev` 启动，`npm run build` 构建。

## 功能

- 句子库：练习、筛选、搜索、自定义添加；每次练习保存机器分、评审分、录音版本与扣分项。
- 评分争议复核：机器分与评审分分差超过 8 分时自动进入待复核，复核结束前该句不得标为已掌握；同一句仅允许一张待复核单，重复触发记入开单冲突（句子、原分、新分、触发规则）。
- 复核处理：评审可确认原分，或填写调整分与依据；调整后生成带原因的新录音版本，旧录音与旧分继续可查；复核结果低于掌握线（85 分）时句子回到练习中。
- 练习数据、版本、复核单与冲突记录均持久化在 localStorage，刷新后待办、版本与状态保持一致。
